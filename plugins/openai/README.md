# NetConverter customer toolkit — private candidate

Use the collection guidance and migration checklist to prepare a network migration,
with or without a NetConverter account. The MCP workflow guides supported migration,
validation and optimization jobs and reviews their evidence. This package contains
no conversion engine or device deployment capability.

Enable this plugin in your supported client and start a fresh conversation. Complete
NetConverter browser sign-in for the hosted MCP connection. Your account's enabled
tools and tenant permissions determine what is available. Where the client requests
advanced OAuth settings, use public client ID `RjSv1z2Gms6iS96s` without a secret.
Never paste passwords, API keys or customer configuration into connection metadata.

Try: “Help me plan a migration and identify missing evidence,” or “Review the evidence
for my NetConverter job.” Verify the bundled skill VERSION before qualification.
Do not enable duplicate standalone copies of these skills. Installation does not
approve uploads, server writes, tenant changes or deployment.

Hosted MCP cannot browse your computer. Local file transport requires the separately
installed NetConverter Terminal and a deliberately configured workspace, for example
`netconverter mcp --workspace "/absolute/customer-folder"`. Folder scope and
disclosure level are separate controls. This plugin does not launch that bridge.

The Claude wrapper also supplies optional migration-architect and evidence-reviewer
roles. They plan and review; return proposed writes to the main guided conversation.
These prompt instructions do not grant or enforce server permissions. Agent support
varies by client; no cross-client agent compatibility is asserted.

These are private qualification artifacts, not an approved public listing. Schema
checks are separate from actual installed-client authentication and workflow tests.
The current portable MCP schema does not accept the OAuth extension illustrated in
the OpenAI guide, so the portable artifact uses HTTPS discovery and no invented
authentication fields. Do not assume direct Codex OAuth is qualified.

Use the client's plugin manager to disable or uninstall this package. Preserve
unrelated instructions, customer files and credentials. For upgrades, retain a
backup and install the selected version; verify its skills in a fresh conversation.
